# 🎬 Movie Recommendation System

## DecodeLabs Artificial Intelligence Project 3

A simple movie recommendation system built using Python.

## Project Objective

The objective of this project is to recommend movies based on user interests and preferences.

The system compares user interests with movie tags and calculates a similarity score.

## Features

- User preference input
- Movie dataset
- Preference matching
- Similarity score calculation
- Movie ranking
- Top movie recommendations
- Command-line interface

## Technologies Used

- Python
- VS Code
- Git
- GitHub
